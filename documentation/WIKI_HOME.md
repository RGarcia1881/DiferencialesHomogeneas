# EDO Lab · Descripción general

## Qué hace

Resuelve **ay″ + by′ + cy = 0** (a ≠ 0) y explica cada paso:

1. Ecuación característica `am² + bm + c = 0`.
2. Discriminante Δ y clasificación del caso.
3. Raíces: reales distintas, reales repetidas o complejas conjugadas.
4. Soluciones particulares y₁, y₂.
5. Solución general `yc = C₁y₁ + C₂y₂`.

## Qué incluye

| Vista | Contenido |
|---|---|
| **Resolver** | Ventana con los 3 coeficientes y ventana con el procedimiento animado. Cada paso tiene un enlace "¿por qué?". |
| **¿Cómo funciona?** | 7 temas: teoría a la izquierda, código real a la derecha, con los valores de tu ecuación. |
| **Tema** | Botón claro/oscuro en la barra superior (se recuerda en el navegador). |
